Case file / 01AI agents / x402 paymentsLive
01
Settlement layer

Assay: every agent payment, verified or refunded

CHALLENGE

x402 lets an AI agent pay for any API, but never get its money back. Across about 800 endpoints on the GoPlausible facilitator, a dead provider or a drifted schema means the USDC is simply gone.

BUILD

Agents call Assay instead of the provider. Assay pays the provider, checks the response against the schema the provider published, then settles or refunds.

OUTCOME

A live guarantee layer that gives agent spending what it lacked: recourse, and a public signal when a provider fails.

Case file / 02Cross-border payroll / ArcLive
02
Stablecoin payments

PayStream: salary that arrives by the second

CHALLENGE

Over 1.5 million low-wage expat workers in the UAE wait 30 days for pay, then lose more of it to expensive remittance corridors home.

BUILD

Salary streamed in USDC on Arc, with a real nanopayment confirming every 60 seconds and CCTP withdrawals to any wallet. Workers sign in with email, no seed phrase.

OUTCOME

Frontend on Vercel, API on Render. Entered in the Ignyte × Circle × Arc Stablecoin Commerce challenge, cross-border payments track.

Case file / 03EdTech / CBTLive
03
Exam platform

QuizOS & Mmuta: from paper tests to proctored CBT

CHALLENGE

Nigerian universities still run tests on paper or informal CBT, with weak anti-cheat, slow marking and no analytics.

BUILD

A full academic portal for FUTO: timed anti-cheat exams, AI-assisted grading, notes with LaTeX maths, and live audio lectures with polls and attendance. Mmuta takes it to every Nigerian school.

Case file / 04Agent economy / Arc · CircleHackathon
04
Multi-agent pipeline

AgentFloat: an agent economy that pays for itself

CHALLENGE

Agent pipelines spend money on every call and leave idle capital earning nothing between tasks.

BUILD

An orchestrator hires Researcher, Analyst and Writer agents and pays each micro-action in sub-cent USDC over x402 on Arc. Idle funds sit in USYC earning T-bill yield; identities are verified on ERC-8004.

OUTCOME

Built with team BusyBrain Labs for the lablab.ai × Arc × Circle hackathon, Agent-to-Agent Payment Loop track, April 2026.

Case file / 05Freelance escrow / CircleLive
05
AI-mediated escrow

Receipt: get paid the moment work is approved

CHALLENGE

Freelancers deliver, then wait, chase and hope. Clients have no neutral way to confirm the work before paying.

BUILD

Clients fund USDC or EURC escrow. The Receipt agent, running Llama 3.3 70B on NVIDIA NIM, evaluates the delivery and releases payment on Arc in under 500 ms.

OUTCOME

Live, with every evaluation sold as an x402-paid endpoint. Built for the Lepton Agents Hackathon by Canteen × Circle, June 2026.
