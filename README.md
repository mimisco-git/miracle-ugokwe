## 📦 Deployment to Vercel

### Option 1: Deploy via Vercel Dashboard (Easiest)

1. **Create a GitHub Repository:**
   ```bash
   cd miracle-portfolio
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```

2. **Deploy on Vercel:**
   - Go to [vercel.com](https://vercel.com)
   - Click "Add New Project"
   - Import your GitHub repository
   - Click "Deploy"
   - Done! Your site will be live at `your-project.vercel.app`

### Option 2: Deploy via Vercel CLI

1. **Install Vercel CLI:**
   ```bash
   npm install -g vercel
   ```

2. **Deploy:**
   ```bash
   cd miracle-portfolio
   vercel
   ```

3. Follow the prompts and your site will be deployed!

### Option 3: Deploy to Netlify

1. **Via Netlify Dashboard:**
   - Go to [netlify.com](https://netlify.com)
   - Drag and drop the `miracle-portfolio` folder
   - Your site is live!

2. **Via Netlify CLI:**
   ```bash
   npm install -g netlify-cli
   netlify deploy --prod
   ```

## 🔧 Local Development

To run the portfolio locally:

```bash
# Navigate to project directory
cd miracle-portfolio

# Option 1: Using Python
python3 -m http.server 3000

# Option 2: Using Node.js
npx serve

# Option 3: Using PHP
php -S localhost:3000
```

Then open `http://localhost:3000` in your browser.

## 🎨 Customization

To customize the portfolio:

1. **Update Content:** Edit the `index.html` file
2. **Change Colors:** Modify the Tailwind classes or gradient colors in the `<style>` section
3. **Add Projects:** Add new project cards in the Projects section
4. **Update Images:** Replace images in the `public/images/` folder
5. **Update Resume:** Replace `Miracles_Updated_Cv.pdf` with your updated resume
